# 2026-09-23 公开版通用修补

本次只同步通用代码，不包含维护者数据库、账户、日志、私人Windows任务或通知渠道。历史仍从2025年开始，网页默认显示2026年以来；每日更新由使用者的agent安排在08:30之后，目标是最新上一个完整交易日。

## 已同步

- 宏观图表按日期合并新旧观测，单日增量不再覆盖整条趋势；隐藏页签按需渲染并重算尺寸。
- 沪深成交额检查三条序列，缺一条也会补查；只有同日存在另外两项时才差分推导。东方财富指数日K成交额与腾讯目标日最终累计额作为备用源，来源与方法在元数据中保留，不能当成ETF成交额。
- 月频检查各子指标，不再只用制造业PMI或M2代表整组成功；自然语言回包漏列时有限补查。继续保留公开版缺月查询，已完成月份不重复查询。存款累计值保留历史、按相邻月份差分，跨年从零重置，不跨缺口差分。
- 宏观新鲜度按发布频率、同批指标和保守窗口判断；正常等待发布与接口失败区分。窗口是排查门槛，并非官方已经发布的证据。DXY日线与FRED H.10周度替代序列禁止混接，美联储目标利率核验最近FOMC决议。
- ETF数据无新增交易日时也检查宏观缓存；需要修复时只重建宏观并同步SQLite，不重新采集ETF。
- 国内指数采用腾讯历史K线，iFinD仅兜底；拒绝非有限价格，限制日期范围，有限重试并保存Node错误正文。正式入口固定UTF-8。ETF采集限流退避，明确额度耗尽时停止，保留断点。
- DeepSeek用只读SQLite先计算指定区间的ETF资金排名、单只合计及四只核心沪深300ETF合计。查询上限为已发布日，缺失不填零，来源区显示真实区间、样本和省略说明；金额合计不交给模型自行累加。

## 未移植的私人配置

- 本机原生iFinD Python SDK及登录配置：公开版仍使用用户自己的iFinD Skill。
- 私人飞书日报、Windows/Codex自动化权限规则：通知继续默认关闭，调度由用户自行设置。
- 研究清洗、研究数据CSV回退、生产目录版式锁及私人修复用历史数值：不进入公开版每日链路。

## 可选月度报告备用源

`config/macro_release_sources.json` 默认空列表。维护者或使用者核实官方报告后，可登记 `month`、`published_at`（YYYY-MM-DD）和 `url`；目前解析器只接受人民银行、新华社、上海金融局的HTTPS来源，且要求两份相邻月份的报告。不会复制私人归档原文，也不会自动猜测未来报告地址。没有核实来源时沿用iFinD与上次成功数据，并保留新鲜度告警。

## 验证边界

回归测试使用临时SQLite与模拟回包，不调用维护者账户，不消耗iFinD或DeepSeek额度。没有在另一台全新Windows电脑执行真实账户的整日采集。升级后应由用户在自己的环境运行 `update.ps1 -Resume` 并查看健康接口和 `runtime/update_status.json`。
